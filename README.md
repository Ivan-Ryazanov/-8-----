# Задание «КТ №8 - Бот - словарь»

Требуется реализовать бота на базе Tg

Функционал:
1) После старта общения, пользователю должно выводиться приветственное сообщение и клавиатура с кнопками "Дай определение" и "Запомни определение"
2) В случае нажатия "Дай определение" пользователю предлагается ввести термин, например "Транскрибация". Затем, бот должен найти в памяти определение для данного термина. Если определение найдено, бот присылает его в ответ. Если не найдено - отправляет текст ошибки. В обоих случаях пользователю должна вернуться клавиатура с кнопками из п. 1
3) В случае нажатия "Запомни определение" пользователю предлагается сначала ввести термин, после чего ему предлагается ввести определение к термину. В конце должно быть отправлено сообщение об успешном сохранении определения. Если термин уже существует в базе на момент первого шага, бот должен отправить ошибку и клавиатуру из п. 1

Между запусками бот должен запоминать все определения.

Бот требуется написать с помощью только стандартных решений .Net, вроде HttpClient. Библиотеки использовать запрещено
